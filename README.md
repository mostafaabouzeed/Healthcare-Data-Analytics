# Healthcare Data Analytics Project

## Project Overview

This project focuses on analyzing healthcare data to understand patient demographics, healthcare costs, insurance coverage, and patient responsibility.

I developed an interactive two-page dashboard using Microsoft Power BI to explore healthcare trends and present meaningful insights through data visualization.

**Note:** This project uses a synthetic dataset created for educational and portfolio purposes. It does not contain real patient information.

## Project Objectives

- Analyze total healthcare costs and patient encounters.
- Compare healthcare costs across departments and medical conditions.
- Understand insurance coverage and patient responsibility.
- Explore patient demographics, including age, gender, and location.
- Analyze patient outcomes and average length of stay.

## Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel
- MySQL (SQL analysis planned)

## Dashboard Pages

### 1. Healthcare Overview

Provides an overview of healthcare performance, including:
- Total healthcare costs
- Total patient encounters
- Unique patients
- Patient responsibility rate
- Healthcare costs by department and insurance type
- Monthly healthcare cost trends
- Patient demographics

### 2. Cost & Insurance Analysis

Focuses on healthcare expenses and insurance coverage, including:
- Total payer coverage
- Total patient responsibility
- Payer coverage rate
- Patient responsibility rate
- Cost breakdown by insurance type
- Patient demographics and outcomes
- Average length of stay by department

## Dataset

The project uses three Excel tables:

- **Patients:** Patient demographics and insurance information.
- **Encounters:** Healthcare visits, departments, costs, dates, and outcomes.
- **Payers:** Insurance-related information.
